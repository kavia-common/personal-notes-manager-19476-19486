# personal-notes-manager-19476-19486

This workspace contains the Nuxt frontend for the Personal Notes application.

Quick start:
- cd notes_frontend
- npm install
- Set NOTES_API_BASE to your backend URL (e.g. http://localhost:3001)
- NOTES_API_BASE=http://localhost:3001 npm run dev

See notes_frontend/README_APP.md for more details.
